# Fond géographique hors connexion

Les fichiers `land.json` et `lakes.json` reproduisent les couches physiques Natural Earth au 1:110 millions. Ils sont sérialisés en JSON compact, sans modification de géométrie ou d’attributs.

- Source : https://github.com/nvkelso/natural-earth-vector
- Terre : `geojson/ne_110m_land.geojson`, Git blob `04811d72fff2701ec67587e30ad8942675b511e3` (127 entités).
- Lacs : `geojson/ne_110m_lakes.geojson`, Git blob `1225bab890f0b29f19089f9ce36820407ee34913` (24 entités).
- Date de récupération : 31 octobre 2026.
- Conditions : https://www.naturalearthdata.com/about/terms-of-use/ — données du domaine public.
- Crédit : Made with Natural Earth, Tom Patterson, Nathaniel Vaughn Kelso et contributeurs / NACIS.

Ce fond représente la géographie actuelle à petite échelle. Il ne constitue pas une source pour les coordonnées bibliques, la géographie antique ou les frontières historiques. Les points et leur provenance documentaire continuent de provenir du corpus de l’Atlas. À fort zoom, les contours restent volontairement généralisés ; les fonds en ligne optionnels offrent davantage de détail.
